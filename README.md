# オーギヤWO ハナハナ予想（クラウド版・iPhoneで完結）

豊橋市・オーギヤWO の **ハナハナシリーズ** だけを対象に、過去の台データと店の癖から
「今日、高設定（設定5・6）が入っている可能性が高い台番号」をランキングにします。
PCは不要です。役割分担は次のとおりです。

- **iPhone（ショートカットのオートメーション）**: 1日数回、アナスロのページを数枚だけ自分の回線で開き、ハナハナの行だけを `inbox/` に送る
  （アナスロや店の公式サイトはクラウド業者のIPからの閲覧を拒否しているため、取得はiPhoneの回線で行います）
- **GitHub（Actions）**: 届いたデータの集計・店の癖の学習・予想ページの作成と公開（無料）

## 見方

予想ページ: `https://<ユーザー名>.github.io/hana-wo/`
Safari で開いて「共有」→「ホーム画面に追加」すると、アプリのように開けます。

ページの内容
- **台別ランキング** … 台ごとの高設定期待度。「平常の×1.5」なら普段の1.5倍入りやすい見込み
- **島マップ** … 台の並びに色分け（濃いほど期待度が高い）
- **予想の答え合わせ** … 毎日出した予想を、後から公開された実データで採点した結果
- **学習した店の癖** … 何のつく日・末尾・角台・前日凹み→上げ などの条件ごとの高設定率
- **過去データでの検証** … 過去の日で予想し直して答え合わせした成績

## 自動で動くタイミング（日本時間）

| いつ | どこで | 内容 |
|---|---|---|
| 毎朝 7:41 ごろ | GitHub | 今日の予想ページを作成 |
| iPhoneのオートメーションの時刻 | iPhone → GitHub | 次に取るべきページ（`data/next.txt`）を数枚取得して送信 → 届くたびに予想を更新 |
| 毎晩 22:41 ごろ | GitHub | 翌朝iPhoneが取りに行くページの一覧を更新 |

※ 過去データ（約1年分）は、iPhoneが1回1ページずつ新しい日から順に取りに行くので、日を追うごとに予想が充実します。

## iPhoneからの操作

- **今すぐ実行したい**: GitHub の `hana-wo` →「Actions」→「ハナハナ予想」→「Run workflow」
- **設定を変えたい**: `config.yaml` を開いて鉛筆マーク（編集）→ 変更して「Commit changes」。次回の実行から反映
  - `islands` … 島の区切り（角台の判定用）。例 `islands: [[668, 677], [678, 687], [693, 703]]`
  - `high_min` … 「高設定」とみなす設定（既定 5）
  - `event_digits` … 旧イベント日の日付末尾（既定 0, 5）
- **動いているか確認**: 「Actions」に緑のチェックが並んでいればOK。赤い×は失敗（ページ上部にも注意が出ます）

## データの取得元

- **アナスロ**（メイン）… iPhoneが取得。全台の G数・差枚・BB・RB（約13か月分）
- **みんレポ**（補助）… GitHubから確認し、新しい日が出たら自動で補完
- データは `data/` フォルダにCSVで保存されます（ハナハナの台のみ）

## しくみ

1. BB・REG回数とゲーム数から、各台・各日の設定を推定（ハナハナホウオウ～天翔～-30 の公表値を使用）
2. 推定結果から店の癖を学習（日付末尾、曜日、台番末尾と日付の一致、角台、前日の凹み・据え置き、台ごとの入りやすさ、店全体の強い日）
3. 過去データで重みを調整して、今日の各台の「設定5以上の確率」を計算

予想は公開データから計算した確率で、結果を保証するものではありません。遊技は余裕のある範囲で。
